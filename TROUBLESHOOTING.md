# 🔧 Решение проблем

## ❌ AuthKeyDuplicatedError

**Ошибка:**
```
telethon.errors.rpcerrorlist.AuthKeyDuplicatedError: The authorization key (session file) was used under two different IP addresses simultaneously
```

**Причина:**
Файл сессии Telegram (`telegram_session.session`) используется одновременно с двух разных IP-адресов:
- С вашего локального компьютера (если вы запускали `web_app.py` или `authorize.py`)
- С сервера Railway

Telegram не разрешает использовать один файл сессии с разных IP одновременно.

**Решение:**

### Шаг 1: Сбросить старую сессию

```bash
python3 reset_session.py
```

Скрипт:
1. Удалит старый файл сессии
2. Попросит ввести номер телефона
3. Попросит ввести код из Telegram
4. Создаст новый чистый файл сессии

### Шаг 2: Загрузить новую сессию на GitHub

```bash
git add telegram_session.session
git commit -m "Новая сессия Telegram"
git push
```

### Шаг 3: Railway автоматически перезапустится

Railway обнаружит изменения и перезапустит приложение с новой сессией.

### Шаг 4: ⚠️ ВАЖНО - Больше не запускайте локально!

После загрузки сессии на GitHub:
- **НЕ** запускайте `web_app.py` на своем компьютере
- **НЕ** запускайте `authorize.py` повторно
- Используйте **ТОЛЬКО** Railway для работы сервера

Локальный запуск вызовет ту же ошибку снова!

### Шаг 5: Завершить старые сессии в Telegram (опционально)

1. Откройте Telegram на телефоне
2. Перейдите в **Настройки** → **Устройства**
3. Завершите все старые/неизвестные сессии
4. Оставьте только активную сессию Railway

## 📱 Если проблема повторяется

Если ошибка AuthKeyDuplicatedError появляется снова:

1. Убедитесь, что вы **не запускаете ничего локально**
2. Проверьте, что файл `.env` на Railway заполнен правильно
3. Убедитесь, что номер телефона, который вы использовали для авторизации, может получать доступ к каналу @utraci

## 💡 Как правильно работать

**Правильно:**
✅ Открыть https://ваш-проект.railway.app/ в браузере
✅ Держать вкладку открытой (можно свернуть браузер, но не закрывать вкладку)
✅ Уведомления приходят через 60 секунд после сообщения в канале

**Неправильно:**
❌ Запускать `python3 web_app.py` на компьютере
❌ Закрывать/обновлять вкладку браузера до получения уведомления
❌ Использовать один файл сессии на нескольких устройствах
