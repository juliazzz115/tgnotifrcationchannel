# ✅ СУПЕР ПРОСТАЯ ИНСТРУКЦИЯ - RAILWAY

Railway - намного проще чем Render! Всё работает из коробки.

---

## 🚀 ШАГ 1: Регистрация (30 секунд)

1. Откройте: https://railway.app
2. Нажмите **"Start a New Project"** или **"Login"**
3. Войдите через **GitHub** (проще всего)

**Бесплатно $5 кредитов в месяц!**

---

## 📦 ШАГ 2: Создание проекта (1 минута)

1. Нажмите **"New Project"**
2. Выберите **"Deploy from GitHub repo"**
3. Выберите репозиторий **`tgnotifrcationchannel`**
4. Выберите ветку **`claude/telegram-desktop-alerts-011EGg3ZAYJcCeuL2bVHbaEe`**
5. Нажмите **"Deploy Now"**

Railway **автоматически** определит что это Python и начнет деплой!

---

## ⚙️ ШАГ 3: Добавить переменные (2 минуты)

1. В проекте Railway откройте вкладку **"Variables"**
2. Нажмите **"New Variable"** и добавьте:

```
API_ID = 12345678
API_HASH = ваш_hash_от_telegram
CHANNEL_ID = @ваш_канал
ALERT_DELAY = 60
PORT = 5000
HOST = 0.0.0.0
```

**Где взять API_ID и API_HASH:**
- https://my.telegram.org/apps
- Войдите через Telegram
- Создайте приложение
- Скопируйте `api_id` и `api_hash`

3. Нажмите **"Add"** для каждой переменной

---

## 🔐 ШАГ 4: Авторизация в Telegram (1 минута)

**ЭТО САМОЕ ВАЖНОЕ!**

После деплоя Railway создаст логи. Telegram попросит авторизацию:

1. В Railway откройте вкладку **"Deployments"**
2. Нажмите на последний деплой
3. Откройте **"View Logs"**
4. Увидите: `Please enter your phone number:`

**НО!** Railway не позволяет вводить в логи.

### Решение:

**Сначала авторизуйтесь локально:**

```bash
cd ~/Desktop/tgnotifrcationchannel
python3 web_app.py
```

Введите:
- Номер телефона (например: +380501234567)
- Код из Telegram
- Пароль (если есть 2FA)

После этого создастся файл **`telegram_session.session`**

**Загрузите его на GitHub:**

```bash
git add telegram_session.session
git commit -m "Добавлена сессия Telegram"
git push
```

Railway автоматически подхватит файл и всё заработает!

---

## 🎉 ШАГ 5: Получить ссылку

1. В Railway откройте вкладку **"Settings"**
2. Найдите раздел **"Domains"**
3. Нажмите **"Generate Domain"**
4. Получите ссылку типа: `https://ваш-проект.up.railway.app`

**Готово!**

## 💡 Если что-то не работает:

### Telegram не подключается:
1. Проверьте логи в Railway
2. Убедитесь что файл `telegram_session.session` загружен в GitHub
3. Проверьте переменные API_ID, API_HASH, CHANNEL_ID

### Сайт не открывается:
1. Проверьте что домен сгенерирован в Settings → Domains
2. Подождите 1-2 минуты после деплоя
