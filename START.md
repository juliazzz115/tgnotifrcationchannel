# 🚀 БЫСТРЫЙ СТАРТ

## Как это работает?

1. **Запускаете сервер** (один раз)
2. **Открываете страницу в браузере** (на любом компьютере)
3. **Оставляете вкладку открытой**
4. Когда приходит сообщение → **БОЛЬШОЕ КРАСНОЕ ОКНО** появляется прямо в браузере!

---

## ШАГ 1: Установка (первый раз)

### Установите Python 3
```bash
# macOS
brew install python

# Проверка
python3 --version
```

### Установите зависимости
```bash
cd /path/to/tgnotifrcationchannel
pip3 install -r requirements.txt
```

---

## ШАГ 2: Настройка Telegram API

### 2.1. Получите ключи

1. Откройте: https://my.telegram.org/apps
2. Войдите через Telegram
3. Создайте приложение (можно написать любые данные)
4. Скопируйте:
   - **api_id** (число)
   - **api_hash** (длинная строка)

### 2.2. Создайте файл .env

```bash
# Скопируйте пример
cp .env.example .env

# Откройте в редакторе
nano .env
```

Заполните:
```
API_ID=12345678
API_HASH=ваш_hash_здесь
CHANNEL_ID=@ваш_канал
ALERT_DELAY=60
```

**Как узнать CHANNEL_ID:**
- Если канал публичный: `@channelname`
- Если приватный: переслать сообщение боту @userinfobot

---

## ШАГ 3: ЗАПУСК!

### Запустите сервер:
```bash
python3 web_app.py
```

Увидите:
```
🚀 Сервер: http://localhost:5000
📱 Откройте эту ссылку в браузере!
```

### Откройте в браузере:
```
http://localhost:5000
```

---

## ШАГ 4: Оставьте вкладку открытой

1. Откройте http://localhost:5000
2. Разрешите уведомления (если попросит)
3. **НЕ ЗАКРЫВАЙТЕ эту вкладку!**
4. Можете свернуть окно браузера

Теперь когда придет сообщение:
- ⚠️ Через 1 минуту появится БОЛЬШОЕ КРАСНОЕ ОКНО
- 🔊 Прозвучит звуковой сигнал
- 📱 Придет системное уведомление
- Окно нельзя закрыть без ввода имени и подтверждения!

---

## Открыть с ДРУГОГО компьютера

Если хотите открыть страницу на другом компьютере в той же сети:

1. Узнайте IP вашего компьютера:
```bash
# macOS/Linux
ifconfig | grep "inet "
```

2. В .env измените:
```
HOST=0.0.0.0
PORT=5000
```

3. На другом компьютере откройте:
```
http://192.168.x.x:5000
```
(замените на ваш IP)

## Автозапуск при включении Mac

Создайте файл `start_server.sh`:
```bash
#!/bin/bash
cd /path/to/tgnotifrcationchannel
python3 web_app.py
```

Сделайте исполняемым:
```bash
chmod +x start_server.sh
```

Добавьте в автозагрузку:
1. Системные настройки → Основные → Объекты входа
2. Нажмите "+" и выберите `start_server.sh`

## Решение проблем

### "pip: command not found"
Используйте `pip3`:
```bash
pip3 install -r requirements.txt
```

### "Port 5000 already in use"
Измените порт в .env:
```
PORT=8000
```

### Окно не появляется
1. Проверьте логи: `tail -f telegram_monitor.log`
2. Убедитесь, что вкладка браузера открыта
3. Проверьте статус подключения на странице

### Первый запуск - нужна авторизация
При первом запуске Telegram попросит:
1. Номер телефона
2. Код из SMS
3. Пароль (если есть 2FA)
