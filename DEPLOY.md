## 🚀 НАСТРОЙКА (ОДИН РАЗ, 5 МИНУТ)

### Шаг 1: Зарегистрируйтесь на Render.com

1. Откройте: https://render.com
2. Нажмите "Get Started" или "Sign Up"
3. Зарегистрируйтесь через GitHub (проще всего)

**Это бесплатно!**

---

### Шаг 2: Подключите ваш GitHub репозиторий

1. В Render нажмите "New +" → "Web Service"
2. Выберите "Connect a repository"
3. Найдите репозиторий `tgnotifrcationchannel`
4. Нажмите "Connect"

---

### Шаг 3: Настройте сервис

Заполните поля:

- **Name**: `telegram-alerts` (или любое имя)
- **Region**: `Frankfurt (EU Central)` (ближе к вам)
- **Branch**: `claude/telegram-desktop-alerts-011EGg3ZAYJcCeuL2bVHbaEe`
- **Runtime**: `Python 3`
- **Build Command**: `pip install -r requirements.txt`
- **Start Command**: `python web_app.py`
- **Instance Type**: `Free`

---

### Шаг 4: Добавьте переменные окружения

В разделе "Environment Variables" добавьте:

1. **API_ID** = ваш API ID (с https://my.telegram.org/apps)
2. **API_HASH** = ваш API Hash
3. **CHANNEL_ID** = ID вашего канала (например: `@channelname`)
4. **ALERT_DELAY** = 60
5. **HOST** = 0.0.0.0
6. **PORT** = 10000

---

### Шаг 5: Нажмите "Create Web Service"

Render начнет деплой (3-5 минут).

После завершения вы получите ссылку типа:
```
https://telegram-alerts-xxxx.onrender.com
```

---

## 🎉 ГОТОВО!

Теперь:
1. Откройте эту ссылку в браузере
2. Оставьте вкладку открытой
3. **ВСЁ!**

Сервер работает в облаке 24/7.
Когда придет сообщение → большое красное окно появится автоматически!

Можно тестировать сколько угодно раз - просто открывайте `/test`

## ⚠️ Важно:

**Бесплатный план Render:**
- Сервис засыпает после 15 минут неактивности
- Просыпается при первом запросе (занимает 30 секунд)
