# 📊 Руководство по расширенной аналитике

## Обзор

Новая система аналитики предоставляет глубокий многоуровневый анализ работы менеджеров с использованием AI (Google Gemini) и интерактивных фильтров.

---

## 🎯 4 Подвкладки

### 1. 📈 Общая аналитика
**Основной dashboard с фильтрами и списком диалогов**

#### Ключевые метрики:
- 📊 Всего диалогов
- ⭐ Средняя оценка (из 10)
- 👤 % представившихся менеджеров
- ⏱️ Среднее время ответа
- ✅ Количество диалогов с отличным качеством
- ⚠️ Количество диалогов с высоким риском оттока

#### 8 Расширенных фильтров:
1. **Дата от/до** - временной диапазон
2. **Качество** - excellent / good / satisfactory / poor / critical
3. **Менеджер** - автоматически заполняется из данных
4. **Представился** - да/нет
5. **Статус решения** - resolved / in_progress / ignored
6. **Уровень риска** - low / medium / high / critical
7. **Сортировка**:
   - Новые первыми
   - Старые первыми
   - Лучшее качество
   - Худшее качество
   - Высокий риск первыми

#### Карточки диалогов показывают:
- Клиент и время
- Менеджер и оценка (0-10)
- Время ответа
- Представился ли менеджер
- Настроение клиента
- Риск оттока
- AI резюме диалога

---

### 2. 👥 По менеджерам
**Детальная статистика по каждому менеджеру**

Каждая карточка менеджера содержит:
- 🏆 **Средняя оценка** (крупно)
- 📈 Всего диалогов
- ✅ % представлений
- ⏱️ Среднее время ответа
- Распределение по качеству:
  - ✅ Отлично
  - 👍 Хорошо
  - ⚠️ Критично

**Использование:**
- Сравнение эффективности менеджеров
- Выявление сильных и слабых сторон
- Планирование обучения

---

### 3. ⏱️ Временная аналитика
**3 интерактивных графика на Chart.js**

#### График 1: Распределение диалогов по времени суток
- **Тип:** Столбчатая диаграмма
- **Данные:** Количество диалогов по часам (0-23)
- **Применение:** Определение пиковых часов нагрузки

#### График 2: Среднее время ответа по часам
- **Тип:** Линейный график
- **Данные:** Среднее время ответа (в минутах) по часам
- **Применение:** Выявление часов с медленным откликом

#### График 3: Качество обслуживания по дням недели
- **Тип:** Столбчатая диаграмма
- **Данные:** Средняя оценка (1-10) по дням недели
- **Применение:** Анализ качества работы в разные дни

---

### 4. 🤖 AI Insights
**Детальная таблица с AI-анализом каждого диалога**

#### Колонки таблицы:
1. **Клиент** - имя + дата/время
2. **Менеджер** - кто вел диалог
3. **Качество** - цветной бейдж (excellent/good/satisfactory/poor/critical)
4. **Настроение клиента** - positive/neutral/negative/mixed
5. **Риск оттока** - low/medium/high/critical
6. **Тема** - main_topic из AI анализа
7. **Рекомендации** - первые 2 рекомендации от AI

## 📊 AI Анализ (Google Gemini)

### Анализируемые параметры (50+ метрик):

#### 1. Настроение и эмоции клиента
- overall_sentiment
- sentiment_score (-1.0 до +1.0)
- client_state (calm/worried/angry/frustrated/confused/satisfied)
- emotion_dynamics

#### 2. Тип запроса
- request_type (information_question / status_update / technical_issue / complaint)
- main_topic
- urgency_level
- client_expectations

#### 3. Представление менеджера
- manager_introduced (true/false)
- manager_name
- greeting_quality
- first_impression

#### 4. Оценка качества (каждый параметр 1-10)
- politeness_score - вежливость
- clarity_score - ясность ответов
- proactivity_score - инициатива
- responsiveness_score - скорость реакции
- empathy_score - эмпатия
- professionalism_score - профессионализм

#### 5. Коммуникация
- communication_style (friendly/professional/formal/cold)
- used_personalization
- tone_consistency
- language_quality

#### 6. Решение проблемы
- resolution_status (resolved/in_progress/waiting/ignored)
- solution_provided
- next_steps_clear
- timeline_given
- follow_up_planned

#### 7. Риски
- risk_level
- churn_risk_level (риск ухода клиента!)
- need_urgent_attention
- escalation_needed
- risks[] - массив конкретных рисков

#### 8. Ключевые моменты
- key_moments[] - важные моменты диалога
- critical_phrases[] - критические фразы
- turning_points[] - переломные моменты

#### 9. Сильные стороны
- strengths[] - что сделано хорошо

#### 10. Проблемы
- key_issues[] - конкретные проблемы
- missed_opportunities[] - упущенные возможности

#### 11. Рекомендации
- suggestions[] - практические советы (3-5 пунктов)
- priority_actions[] - приоритетные действия
- training_needs[] - потребности в обучении

#### 12. Итоговая оценка
- overall_quality (excellent/good/satisfactory/poor/critical)
- client_satisfaction_estimate (1-10)
- summary - краткое резюме

## 🚀 Как использовать

### Для менеджеров:
1. **Мониторинг собственной эффективности**
   - Перейти на вкладку "По менеджерам"
   - Найти свою карточку
   - Обратить внимание на средний балл и % представлений

2. **Работа над ошибками**
   - Вкладка "AI Insights"
   - Найти свои диалоги с низкой оценкой
   - Изучить рекомендации AI

### Для руководителей:
1. **Общий мониторинг**
   - Вкладка "Общая аналитика"
   - Ключевые метрики наверху
   - Фильтр по качеству = "critical" или "poor"

2. **Выявление проблем**
   - Фильтр "Уровень риска" = high/critical
   - Сортировка "Высокий риск первыми"
   - Срочный контакт с клиентами из списка

3. **Оценка работы команды**
   - Вкладка "По менеджерам"
   - Сравнение средних оценок
   - Планирование обучения для отстающих

4. **Планирование ресурсов**
   - Вкладка "Временная аналитика"
   - График "Распределение диалогов по времени"
   - Выделение менеджеров на пиковые часы

### Для аналитиков:
1. **Глубокий анализ**
   - Экспорт данных в CSV
   - Дополнительная обработка в Excel/Python
   - Построение трендов

2. **Поиск паттернов**
   - Фильтры + графики
   - Выявление закономерностей (качество хуже по пятницам? время ответа выше вечером?)

## 💡 Лучшие практики

### Ежедневный мониторинг (5 минут)
1. Открыть "Общую аналитику"
2. Фильтр: сегодняшняя дата
3. Проверить "Высокий риск" - если есть, принять меры
4. Проверить средний балл - должен быть >7

### Еженедельный анализ (15 минут)
1. Экспортировать данные за неделю
2. Вкладка "По менеджерам" - сравнить результаты
3. Вкладка "Временная" - выявить пиковые часы
4. Обсудить результаты на встрече команды

### Ежемесячный обзор (30 минут)
1. Фильтр: последние 30 дней
2. Вкладка "AI Insights" - детальный анализ проблемных диалогов
3. Создание плана обучения на основе "training_needs"
4. Оптимизация графика работы на основе временной аналитики

## 🐛 Возможные проблемы

### "Нет диалогов" в списке
**Причина:** Слишком строгие фильтры
**Решение:** Нажать "Сбросить все" в фильтрах

### Графики не отображаются
**Причина:** Недостаточно данных для построения
**Решение:** Собрать больше диалогов (минимум 5-10)

### "н/д" в колонке менеджера
**Причина:** AI не смог определить имя менеджера
**Решение:** Менеджеры должны представляться в начале диалога

### Экспорт CSV с кракозябрами
**Причина:** Excel открывает в неправильной кодировке
**Решение:** Импорт данных с указанием UTF-8
