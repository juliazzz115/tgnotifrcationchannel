# Telegram Desktop Alerts

Система уведомлений для Telegram канала с обязательным подтверждением просмотра сообщений.

## 📋 Описание

Эта программа отслеживает новые сообщения в указанном Telegram канале и через минуту после получения сообщения показывает большое немодальное окно на рабочем столе, которое:

- ⚠️ Показывается поверх всех окон
- 🔒 Не закрывается без ввода имени и подтверждения
- 📝 Отображает полный текст сообщения
- ✅ Требует явного подтверждения проверки

## 🎯 Возможности

- Мониторинг любого Telegram канала в реальном времени
- Автоматическая задержка на 1 минуту перед показом уведомления
- Большое заметное окно с красным фоном для привлечения внимания
- Обязательный ввод имени пользователя
- Обязательное подтверждение проверки сообщений
- Логирование всех событий

## 🔧 Установка

### 1. Требования

- Python 3.8 или выше
- Аккаунт Telegram
- API credentials от Telegram

### 2. Установка зависимостей

```bash
# Клонируйте репозиторий (или скачайте файлы)
cd tgnotifrcationchannel

# Установите зависимости
pip install -r requirements.txt
```

### 3. Получение Telegram API credentials

1. Перейдите на https://my.telegram.org/apps
2. Войдите в свой аккаунт Telegram
3. Создайте новое приложение (или используйте существующее)
4. Скопируйте `api_id` и `api_hash`

### 4. Настройка конфигурации

1. Скопируйте файл `.env.example` в `.env`:

```bash
cp .env.example .env
```

2. Откройте файл `.env` и заполните необходимые данные:

```env
# Telegram API credentials (с https://my.telegram.org/apps)
API_ID=12345678
API_HASH=0123456789abcdef0123456789abcdef

# ID или username канала для мониторинга
# Варианты:
# - Числовой ID (например: -1001234567890)
# - Username канала (например: @mychannel)
CHANNEL_ID=@mychannel

# Задержка перед показом окна в секундах (по умолчанию 60)
ALERT_DELAY=60
```

### 5. Получение ID канала

Есть несколько способов узнать ID канала:

#### Способ 1: Через бота @userinfobot
1. Перешлите любое сообщение из канала боту @userinfobot
2. Бот пришлет информацию, включая ID канала

#### Способ 2: Через username канала
Если у канала есть публичный username (например, @mychannel), можно использовать его напрямую:
```env
CHANNEL_ID=@mychannel
```

#### Способ 3: Через веб-версию Telegram
1. Откройте канал в веб-версии Telegram (web.telegram.org)
2. В URL будет ID канала (число после `#`)

## 🚀 Запуск

### Первый запуск

При первом запуске программа попросит вас авторизоваться в Telegram:

```bash
python telegram_monitor.py
```

Вам нужно будет:
1. Ввести номер телефона
2. Ввести код подтверждения из Telegram
3. Если включена двухфакторная аутентификация - ввести пароль

После успешной авторизации создастся файл сессии `telegram_monitor_session.session`, и в следующий раз авторизация не потребуется.

### Обычный запуск

```bash
python telegram_monitor.py
```

Программа будет работать в фоновом режиме и ждать новых сообщений в канале.

### Остановка

Нажмите `Ctrl+C` для остановки программы.

## 🔍 Тестирование окна уведомления

Чтобы протестировать внешний вид окна без подключения к Telegram:

```bash
python alert_window.py
```

Откроется тестовое окно с примером сообщения.

## 📊 Логирование

Все события записываются в файл `telegram_monitor.log`:
- Запуск и остановка программы
- Получение новых сообщений
- Показ окон уведомлений
- Подтверждения пользователей
- Ошибки

Формат лога:
```
2025-12-04 15:32:45 - telegram_monitor - INFO - Получено новое сообщение в канале...
2025-12-04 15:33:45 - alert_window - INFO - Показываю окно уведомления
2025-12-04 15:34:12 - alert_window - INFO - Уведомление подтверждено пользователем: Иван
```

## 🎨 Внешний вид окна

Окно уведомления:
- Занимает 80% экрана по центру
- Имеет красный фон для привлечения внимания
- Показывается поверх всех окон
- Содержит:
  - ⚠️ Заголовок с предупреждением
  - 🕐 Время получения сообщения
  - 📝 Полный текст сообщения
  - 👤 Поле для ввода имени
  - ✅ Чекбокс подтверждения
  - 🔘 Кнопка "Подтвердить и закрыть"

## 🔐 Безопасность

- Файл `.env` содержит конфиденциальные данные и не должен публиковаться (уже добавлен в `.gitignore`)
- Файл сессии `*.session` также конфиденциален и не должен публиковаться
- API credentials дают доступ к вашему Telegram аккаунту - храните их в безопасности

## ⚙️ Настройка задержки

По умолчанию окно появляется через 60 секунд после получения сообщения. Чтобы изменить задержку, отредактируйте параметр `ALERT_DELAY` в файле `.env`:

```env
# Показывать окно через 30 секунд
ALERT_DELAY=30

# Показывать окно через 2 минуты (120 секунд)
ALERT_DELAY=120
```

## 🐛 Решение проблем

### Ошибка: "Необходимо заполнить API_ID, API_HASH и CHANNEL_ID в файле .env"
- Убедитесь, что файл `.env` создан и заполнен
- Проверьте, что все параметры указаны без кавычек

### Ошибка при подключении к каналу
- Проверьте правильность CHANNEL_ID
- Убедитесь, что ваш аккаунт Telegram является участником канала
- Для приватных каналов используйте числовой ID, а не username

### Окно не появляется
- Проверьте логи в файле `telegram_monitor.log`
- Убедитесь, что программа запущена и ждет сообщений
- Отправьте тестовое сообщение в канал

### Программа не запускается
- Убедитесь, что установлены все зависимости: `pip install -r requirements.txt`
- Проверьте версию Python: `python --version` (должна быть 3.8+)

## 🤝 Автозапуск при включении компьютера

### Windows

1. Создайте `.bat` файл (например, `start_monitor.bat`):
```batch
@echo off
cd /d "C:\path\to\tgnotifrcationchannel"
python telegram_monitor.py
```

2. Нажмите `Win+R`, введите `shell:startup`
3. Скопируйте `.bat` файл в открывшуюся папку

### Linux

1. Создайте systemd service (`/etc/systemd/system/telegram-monitor.service`):
```ini
[Unit]
Description=Telegram Desktop Alerts Monitor
After=network.target

[Service]
Type=simple
User=your_username
WorkingDirectory=/path/to/tgnotifrcationchannel
ExecStart=/usr/bin/python3 /path/to/tgnotifrcationchannel/telegram_monitor.py
Restart=always

[Install]
WantedBy=multi-user.target
```

2. Активируйте службу:
```bash
sudo systemctl enable telegram-monitor
sudo systemctl start telegram-monitor
```

### macOS

Создайте LaunchAgent (`~/Library/LaunchAgents/com.telegram.monitor.plist`):
```xml
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN" "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
<plist version="1.0">
<dict>
    <key>Label</key>
    <string>com.telegram.monitor</string>
    <key>ProgramArguments</key>
    <array>
        <string>/usr/bin/python3</string>
        <string>/path/to/tgnotifrcationchannel/telegram_monitor.py</string>
    </array>
    <key>RunAtLoad</key>
    <true/>
    <key>WorkingDirectory</key>
    <string>/path/to/tgnotifrcationchannel</string>
</dict>
</plist>
```

Загрузите agent:
```bash
launchctl load ~/Library/LaunchAgents/com.telegram.monitor.plist
```
