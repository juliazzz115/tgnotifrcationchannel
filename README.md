# Telegram Dialog Analytics - Система аналитики диалогов

Расширенная система мониторинга и анализа диалогов Telegram с использованием AI.

## Основные возможности

### 1. Мониторинг диалогов
- Отслеживание неотвеченных сообщений клиентов
- Автоматическое сканирование каждые 3 минуты
- Фильтрация по статусам (новые, в работе, решено)
- Назначение ответственных менеджеров
- Добавление заметок к диалогам

### 2. Детальная аналитика с AI (12 категорий)
- **Настроение и эмоции клиента**: 
  - Анализ sentiment (-1 до +1)
  - Состояние клиента (спокоен/встревожен/зол/доволен)
  - Динамика эмоций в диалоге
  
- **Тип и тема запроса**:
  - Определение типа (вопрос/статус/жалоба/счет/риск ухода)
  - Конкретная тема запроса
  - Уровень срочности (низкий/средний/высокий/критический)

- **6 метрик качества работы менеджера (1-10)**:
  - Вежливость (тон, приветствия, благодарности)
  - Ясность (понятность ответов, структурированность)
  - Проактивность (инициатива, предложение решений)
  - Скорость реакции (готовность помочь)
  - Эмпатия (понимание ситуации клиента)
  - Общий профессионализм

- **Риски и предупреждения**:
  - Уровень риска проблем с клиентом
  - Риск ухода клиента (churn risk)
  - Необходимость срочного внимания руководителя
  - Конкретные выявленные риски

- **Детальная информация**:
  - Ключевые моменты диалога
  - Критические фразы
  - Сильные стороны менеджера
  - Проблемы и недочеты
  - Упущенные возможности
  - 3-5 конкретных рекомендаций

- **AI модель**: Google Gemini 1.5 Flash
- **Язык ответа**: Русский (все значения на русском языке)

### 3. Визуализация данных
- Графики распределения времени ответа
- Диаграммы качества обслуживания
- Статистика за день
- Процент превышения SLA
- Процент представившихся менеджеров

### 4. Система уведомлений
- WebSocket real-time обновления
- Звуковые и визуальные алерты
- Модальные окна для критичных сообщений

## Установка

### 1. Клонирование репозитория
```bash
git clone <repository-url>
cd telegram-analytics
```

### 2. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 3. Настройка переменных окружения
```bash
cp .env.example .env
```

Отредактируйте файл `.env`:
```
API_ID=your_api_id
API_HASH=your_api_hash
GOOGLE_AI_KEY=AIzaSyBoYgQMK5cydwDThxovjsRdyUEgcIIu2_g
PORT=5000
```

### 4. Получение API credentials

#### Telegram API:
1. Перейдите на https://my.telegram.org
2. Войдите с вашим номером телефона
3. Перейдите в "API development tools"
4. Создайте новое приложение
5. Скопируйте `API_ID` и `API_HASH`

#### Google AI API (опционально):
- API ключ уже предоставлен в .env.example
- Для получения своего ключа: https://makersuite.google.com/app/apikey

### 5. Первый запуск
```bash
python web_app.py
```

Откройте браузер: http://localhost:5000

## Создание сессии Telegram

1. При первом запуске откройте `/setup`
2. Введите номер телефона в формате +7XXXXXXXXXX
3. Введите код подтверждения из Telegram
4. Скопируйте `SESSION_STRING`
5. Добавьте в переменные окружения (Railway/Heroku) или в `.env`

## Использование

### Навигация

Система имеет 4 основные вкладки:

1. **Диалоги** (`/manager`) - управление неотвеченными диалогами
2. **Аналитика** (`/analytics`) - детальная статистика и анализ
3. **Архивы** (`/archives`) - история данных по дням для руководства
4. **Уведомления** (`/messages`) - система алертов

### Работа с диалогами

1. **Новые диалоги** отображаются красным
2. **Критичные** (негатив или >2ч без ответа) имеют пульсацию
3. Для каждого диалога доступно:
   - Назначение ответственного
   - Добавление заметки
   - Открытие чата в Telegram
   - Создание задачи
   - Отметка как "Решено"

### Аналитика

На странице аналитики вы увидите:

- **Общая статистика**:
  - Всего диалогов за день
  - Среднее время ответа
  - Количество превышений SLA
  - % представившихся менеджеров

- **Графики**:
  - Распределение по времени ответа
  - Качество обслуживания

- **Детальный анализ каждого диалога**:
  - Время ожидания ответа
  - Представился ли менеджер
  - Наличие приветствия
  - Настроение клиента
  - 6 метрик качества (вежливость, ясность, проактивность, скорость, эмпатия, профессионализм)
  - Тема запроса и срочность
  - Ключевые моменты диалога
  - Сильные стороны и проблемы
  - Упущенные возможности
  - AI рекомендации

### Архивы данных

На странице архивов (`/archives`) доступно:

- **Автоматическая архивация**:
  - Каждый день в **7:00 утра** данные за предыдущий день автоматически сохраняются
  - После архивации данные обнуляются для нового рабочего дня
  - В логах появится: `🕖 7:00 - АРХИВАЦИЯ И ОБНУЛЕНИЕ ДАННЫХ`

- **Форматы архивов**:
  - **JSON** - полные данные с AI анализом (для разработчиков)
  - **CSV** - упрощенная версия для Excel (для руководства)

- **Хранение и доступ**:
  - Архивы хранятся 30 дней
  - Автоматическое удаление архивов старше 30 дней
  - Скачивание в 1 клик
  - Ручное создание архива в любой момент

- **CSV файл содержит**:
  - Имя клиента, время, дата
  - Имя менеджера, представился ли
  - Время ответа в минутах
  - Все 6 метрик качества (1-10)
  - Тему запроса, срочность
  - Настроение клиента
  - Статус решения, уровень риска
  - Резюме диалога

- **Использование для руководства**:
  - Ежедневные отчеты в Excel
  - Сравнение работы менеджеров
  - Выявление трендов и проблем
  - Планирование обучения

## Критерии оценки

### Время ответа
- **Отлично**: < 15 минут
- **Хорошо**: 15-30 минут
- **Приемлемо**: 30-60 минут
- **Долго**: 1-1.5 часа
- **Очень долго**: > 1.5 часа ⚠️ SLA нарушен

### Профессионализм (AI оценка)
- **8-10**: Отличный уровень
- **6-7**: Хороший уровень
- **< 6**: Требуется улучшение

## API Endpoints

### GET /api/dialogs
Получить список неотвеченных диалогов с аналитикой

### GET /api/analytics
Получить полную аналитику за день

### POST /api/update_status
Обновить статус диалога
```json
{
  "dialog_id": 123456,
  "status": "task",
  "manager": "Влад",
  "note": "Клиент ждет звонка"
}
```

### GET /api/export_csv
Экспорт диалогов в CSV

## WebSocket события

### Клиент → Сервер
- `connect` - подключение
- `confirm_message` - подтверждение просмотра

### Сервер → Клиент
- `dialogs_update` - обновление списка диалогов
- `analytics_update` - обновление аналитики
- `new_unanswered` - новый неотвеченный диалог
- `status_changed` - изменение статуса

## Деплой на Railway

### Быстрый старт

1. **Подключите GitHub репозиторий**:
   - Откройте [Railway](https://railway.app)
   - New Project → Deploy from GitHub repo
   - Выберите репозиторий `tgnotifrcationchannel`

2. **Настройте переменные окружения**:
   
   Обязательные:
   ```
   API_ID=30416394
   API_HASH=956bff209c...
   SESSION_STRING=1AQAAAABT...  (получите через /setup)
   GOOGLE_AI_KEY=AIzaSy...      (ваш ключ API)
   PORT=8080
   ```

3. **Получите Google AI ключ**:
   - Перейдите на https://aistudio.google.com/app/apikey
   - Войдите через Google аккаунт
   - Нажмите "Create API Key"
   - Скопируйте ключ в переменную `GOOGLE_AI_KEY`

4. **Создайте SESSION_STRING**:
   - После первого деплоя откройте `your-app.railway.app/setup`
   - Введите номер телефона
   - Введите код из Telegram
   - Скопируйте SESSION_STRING
   - Добавьте в Variables на Railway
   - Перезапустите приложение

### Проверка работы

После деплоя проверьте логи Railway:
```
✅ АВТОРИЗОВАН: MCGROUP | Guidance (@mcgrouppl)
✅ Google AI анализ выполнен успешно
📊 Найдено неотвеченных диалогов: X
```

Если видите `Google AI API error: 403`:
- Проверьте что `GOOGLE_AI_KEY` установлен
- Получите новый ключ на https://aistudio.google.com/app/apikey
- Проверьте что ключ активирован для Gemini API

Чтобы исключить определенные чаты из мониторинга, отредактируйте в `web_app.py`:

```python
    "законы", 
    "название_чата"
]
```
