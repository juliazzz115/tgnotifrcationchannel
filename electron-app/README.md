# Telegram Alerts - Desktop App

Electron приложение для уведомлений из Telegram канала @utraci.

## Установка и сборка

### Установка зависимостей:
```bash
npm install
```

### Запуск в режиме разработки:
```bash
npm start
```

### Сборка DMG для macOS:
```bash
npm run build:dmg
```

Готовый DMG файл появится в папке `dist/`.

## Как работает

- Приложение загружает Railway сайт: https://tgnotifrcationchannel-production.up.railway.app/
- Иконка в menu bar (правый верхний угол Mac)
- При новом уведомлении окно автоматически разворачивается на весь экран
- Можно свернуть/закрыть окно - приложение продолжит работать в фоне
- Клик на иконку в menu bar - показать/скрыть окно

## Возможности

✅ Автоматическое разворачивание окна при уведомлении
✅ Работа в фоне (menu bar icon)
✅ Полноэкранный режим при новых сообщениях
✅ Все функции веб-версии сохранены

## Примечание

Для сборки DMG файла требуется macOS.
